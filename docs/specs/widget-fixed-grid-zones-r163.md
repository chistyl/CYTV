# CYTV R163 — 固定分區與既有天氣避讓版

## 開發基準
- 基礎：CYTV R162 小工具欄列即時預覽版。
- 保留 R162 欄數 1–4、列數 1–3、即時預覽、取消／儲存行為。
- 保留 R161/R162 第三方 AppWidgetHostView 原生內容與互動，不修改第三方 APP。

## 固定分區
1. 管理頁與桌面實際工作區均使用設定的固定欄列 Grid。
2. 每個欄列座標都是獨立區塊，空白區仍保留原尺寸，不因其他區塊沒有小工具而折疊或拉伸。
3. 管理頁每個空白區塊提供「新增小工具」入口；新增後放入使用者選取的原區塊。
4. 頁面上方「新增小工具」入口放入第一個可用空白區塊。
5. 新增、移除、重新啟動後，既有小工具的區塊位置不變。
6. 區塊索引與 AppWidget ID 持久化；欄列縮小造成可視容量不足時，保留超出容量的資料，不刪除、不覆蓋，擴大欄列後可恢復。
7. 移除小工具只清空該區塊，其他區塊不重新排列。
8. 保留遙控器焦點、AppWidgetHost 原生互動及既有移除確認流程。

## 天氣預報避讓（不得重新設計天氣）
1. 以目前 CYTV 既有天氣預報功能、實際位置及尺寸為準。
2. 今日／一週天氣沿用既有同一個卡片外框、位置錨點及尺寸；不得因 R163 改變天氣內容、樣式、位置或大小。
3. 小工具工作區沿用現有天氣啟用避讓間距（目前程式既有 210dp 預留）；天氣關閉時沿用原本間距。
4. 一般小工具欄列配置只能作用於避開天氣預報後的工作區，不得覆蓋天氣卡片，也不得讓小工具反向推擠或拉伸天氣卡片。
5. 不新增另一套天氣位置設定或天氣專用新尺寸。

## 實機驗收
- [ ] 1×1、2×1、3×2、4×3 區塊數與座標正確。
- [ ] 從非第一個空白區新增小工具，新增後仍在指定區塊。
- [ ] 新增第二個小工具，第一個位置與尺寸不變。
- [ ] 移除小工具後只有該區塊變空白。
- [ ] 重啟後區塊指派維持不變。
- [ ] 欄列縮小再放大，不遺失超出目前可視容量的小工具。
- [ ] 今日天氣／一週天氣維持 R162 前既有位置與尺寸，小工具區不重疊。
- [ ] 遙控器焦點、原生 Widget 操作、720p／1080p 顯示正常。
- [ ] R162 欄列即時預覽、取消及儲存行為不退化。
