# CYTV R162 — 小工具欄列即時預覽

- 基礎版本：R161 桌面融合美化版
- 分支：feature/widget-layout-live-preview-r162

## 欄列設定視窗
- 欄數 1–4、列數 1–3。
- 調整任一 NumberPicker 時，預覽格立即重排，不必先儲存。
- 預覽顯示目前配置的欄 × 列及對應數量的示意小工具格。
- 按取消不寫入設定；按儲存才保存欄列值。
- 保留既有桌面小工具管理、新增／移除及桌面顯示功能。

## 驗收
- [ ] 1×1、1×3、2×2、3×2、4×3 即時預覽排列正確。
- [ ] 快速連續調整欄列時預覽同步更新。
- [ ] 取消不保存；儲存後重新開啟仍顯示已保存數值。
- [ ] TV 遙控器可操作兩個 NumberPicker、取消與儲存。
- [ ] 720p／1080p 視窗不裁切。
