# CYTV R161 — 第三方小工具桌面融合美化

## 基準
- 基於 CYTV R160：1a89549e84323369b40735897ce7d4f475e525bc
- 分支：feature/desktop-widget-polish-r161
- R160 保留不變；R161 獨立開發與驗收。

## 視覺方向
- 以 CYTV 黑色桌面與 Apple TV 深色簡約風格為主。
- 移除 CYTV 額外套上的不透明深色卡片底色、圓角框線與厚重外框。
- 小工具容器透明，不替第三方 Widget 再加一層底板。
- 以桌面留白與間距建立層次：小工具間距 9dp 水平、7dp 垂直；區域與 Grid 保留適當呼吸空間。
- 不增加標題、管理按鈕、啟動捷徑或空白提示。

## 功能保護
- 保留 Android AppWidgetHostView 原生內容與互動。
- 不修改第三方 APP 的 RemoteViews、按鈕、文字或內部配色。
- 若第三方 Widget 自己繪製灰色／白色背景，CYTV 外層透明化不會強制移除該背景；避免破壞第三方 Widget 的可讀性與點擊區域。
- 保留既有欄數 1–4、列數 1–3、Widget 管理頁與保存機制。
- 保留 R159/R160 天氣卡片固定位置與尺寸要求。

## 實機驗收
- [ ] CYTV 不再額外顯示厚重底板、邊框或卡片底色。
- [ ] 第三方 Widget 自身背景按提供者原設計顯示。
- [ ] 小工具與黑色桌面、天氣卡片及 APP Dock 間距協調。
- [ ] 遙控器焦點及 Widget 原生控制仍可操作。
- [ ] 720p／1080p 顯示比例正常。
- [ ] 重新啟動後小工具仍保留。
