# CYTV R160 — 桌面第三方小工具顯示與欄列配置

## 開發基準
- 前一版：CYTV R159
- 分支：`feature/desktop-widget-layout-r160`
- 基底提交：`c7e69fd1f6499107974a2d8d1105a4f8c4d8ed8a`
- 本版維持 Android 原生 App Widget Host，不修改第三方 APP 或 Widget RemoteViews。

## 桌面顯示
1. 主桌面只顯示使用者已新增的第三方 Widget 本體。
2. 主桌面不顯示「桌面小工具」標題、新增、管理、移除或啟動按鈕。
3. 尚未新增 Widget 時，桌面小工具區完全隱藏，不顯示空白提示，也不佔用版面。
4. Widget 外層採 CYTV 深色圓角框與細邊線；Widget 內容仍由原提供者輸出。
5. Widget 的操作由 Android AppWidgetHostView 處理，保留原生互動。

## 管理入口與設定
- 從桌面既有設定選單的「第三方小工具」進入管理頁。
- 管理頁保留新增、移除、欄列設定、返回桌面。
- 欄數使用既有 1–4 欄設定；顯示列數使用既有 1–3 列設定。
- 欄列設定控制桌面 GridLayout 與可視工作區高度；超出可視範圍時由工作區垂直捲動。

## 天氣卡片相容性
- 延續 R159 天氣卡片固定位置與固定尺寸處理。
- 一天／一週切換不得改變天氣卡片外框位置與尺寸。
- 小工具區仍依天氣卡片啟用狀態保留上方間距，避免重疊。

## 驗證界線
- GitHub Actions 的單元測試與 APK 建置成功，只代表 CI 建置通過。
- 720p／1080p 實際版面、遙控器焦點、第三方 Widget 互動及天氣卡片重疊情況，仍須在實機驗收。
